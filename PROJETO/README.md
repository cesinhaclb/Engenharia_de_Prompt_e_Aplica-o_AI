# 📊 Dashboard de Gestão - Aula 10

## Projeto Completo de Aplicação Web com HTML, CSS e JavaScript

Aplicação profissional para gerenciar e acompanhar informações essenciais de seu negócio em tempo real.

---

## ✨ Funcionalidades Principais

### 📈 **Dashboard Principal**
- **Métricas em Tempo Real:**
  - 📦 Estoque Total
  - 💰 Vendas Mensais
  - 👥 Total de Clientes
  - ⚡ Produtos em Pronta Entrega

- **Gráfico de Vendas:** Visualização interativa com Chart.js
- **Resumo Rápido:** Cards informativos com ações rápidas

### 📋 **Gerenciamento de Estoque**
- Tabela completa de produtos
- Status de estoque (Em Estoque, Baixo, Crítico)
- Edição rápida de produtos
- Alertas de produtos com baixo estoque

### 💰 **Histórico de Vendas**
- Registro de todas as vendas
- Informações: Cliente, Produto, Quantidade, Valor
- Status de cada venda
- Adicionar novas vendas

### 🚚 **Gerenciamento de Entregas**
- Rastreamento completo de entregas
- **Localidade** de cada entrega
- **Funcionário designado** com status de disponibilidade ✅
- Data agendada
- Status em tempo real

### 👥 **Base de Clientes**
- Lista de todos os clientes
- Informações: Email, Telefone, Cidade
- Histórico de compras
- Adicionar novos clientes

### 👤 **Equipe de Funcionários**
- **Status de disponibilidade** em destaque ✅/🔄
- Cargo e região de atuação
- Contato
- Número de entregas do dia
- Layout em cards organizados

### ⚡ **Produtos Pronta Entrega**
- Lista organizada por **localidade** 📍
- **Funcionário designado** com disponibilidade
- Quantidade disponível
- Valor dos produtos
- Botão para agendar entrega

## 🚀 Como Usar

### 1. **Baixar ou Clonar**
```bash
git clone https://github.com/cesinhaclb/Engenharia_de_Prompt_e_Aplica-o_AI.git
cd PROJETO/aula_10
```

### 2. **Abrir no Navegador**
- Abra o arquivo `index.html` diretamente em seu navegador
- Ou utilize um servidor local (exemplo com Python):
```bash
python -m http.server 8000
# Acesse: http://localhost:8000
```

### 3. **Navegação**
- Use a sidebar esquerda para navegar entre as seções
- Clique nos menu items para trocar de seção
- Todos os dados são dinâmicos e responsivos
